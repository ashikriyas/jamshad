# Royal Wedding Invitation — Mohammed Jamshad K.A & Ayishath Safwana 💍

A luxury, interactive digital wedding invitation web application celebrating the Nikah of **Mohammed Jamshad K.A** and **Ayishath Safwana** on **Saturday, 19th December 2026** at Baithul Aysha, Paika.

## ✨ Features

- **3D Royal Envelope & Wax Seal Opening**: Interactive envelope unsealing with celebratory confetti burst.
- **Golden Stardust & Sparkles**: Custom HTML5 Canvas particle animation.
- **Accurate Event Details**:
  - Arabic Bismillah calligraphy & Quranic verse (Surah Ar-Rum 30:21).
  - Groom & Bride showcase cards with lineage and residence.
  - Event schedule: Nikah after Asar Namaz.
  - Venue: Baithul Aysha, Manavaty Nagar Road, Kunhipara, Paika.
- **Live Countdown Timer**: Real-time counter to the Nikah ceremony.
- **Add to Calendar**:
  - One-click Google Calendar integration.
  - Downloadable iCal (.ics) file for Apple & Outlook calendars.
- **Venue & Navigation**: Google Maps direct link and copy address button with toast notification.
- **RSVP Form**: Interactive attendance confirmation with one-tap WhatsApp reply.
- **Guestbook / Duas Wall**: Well-wishers can post prayers and blessings with instant confetti feedback.
- **Ambient Soundtrack**: Relaxing pentatonic chime/harp audio synthesized via Web Audio API with equalizer controls.
- **WhatsApp Share**: Quick share button with pre-formatted invitation text.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production
```bash
npm run build
```
The output will be placed in the `dist/` directory, ready to deploy to Vercel, Netlify, or GitHub Pages.
